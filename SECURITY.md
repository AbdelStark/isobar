# Local trust boundary

Isobar is a trusted local research application, not a multi-user hosted service. The server binds to loopback, rejects foreign Origin and Host headers, limits request size, and serves only built browser assets. Do not place it behind a public proxy or expose its port to a network.

Scenario JSON is data, never executable code. Recorded model actions are validated against the same contract as classical and human actions. No uploaded Python plugins, subprocess commands or hosted model calls are executed.

Scenario classification is preserved in run artifacts. Public export rejects private scenarios. This is an application guardrail, not an information-flow proof: anyone with local filesystem access can read local truth bundles. Actor views are filtered by the kernel; post-run truth access is an explicit research mode, not a multiplayer authorization mechanism.

Do not commit private scenario mappings, source documents, credentials or unreviewed results. Keep confidential inputs outside this repository, or in ignored `private/` only when their governing policy allows it. No collaborators or hosted deployment are configured by the MVP.

Checksums detect changed artifacts; deterministic re-execution checks the implementation's outputs. Neither establishes authorship, external validation, or correctness of world assumptions. Report security concerns privately to the repository owner rather than publishing sensitive scenarios.
